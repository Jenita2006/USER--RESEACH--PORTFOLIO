## User Research

The user research phase focused on understanding the needs, behaviours, and challenges of individuals seeking mental health support through a mobile application.

### Research Methods
- User Interviews
- Online Surveys
- Competitor Analysis

### Key Findings
- Users prefer a simple and calming interface.
- Easy navigation is essential for quick access to resources.
- Privacy and data security are major concerns.
- Mood tracking and journaling are among the most desired features.
- Personalized recommendations improve user engagement.

### User Pain Points
- Existing apps can feel overwhelming with too many features.
- Difficulty maintaining a consistent self-care routine.
- Limited access to reliable mental health resources.
- Complicated onboarding and navigation.

### Design Goals
- Create an intuitive and accessible user experience.
- Promote daily wellness through simple interactions.
- Build trust with a clean and secure interface.
- Encourage consistent engagement with personalised features.
